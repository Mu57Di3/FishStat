# FishStat
Дополнение для игры World of Warcraft ретеил версии. Собирает статистику по улову профессии рыбалка.

## Функции

- Статистика сессии создается новая по команде `/reload` или при выходе/входе, так же сохраняется общая статистика
- Интеграция с аддоном Auctionator для получения цен с аукциона и отображения на страницы сессии, можно понять примерную сумму которую можно заработать.
- Автоматически скрывается во время боя и сворачивается в иконку у карты. Системная иконка рыбалки
- В каждой зоне показывается уровень навыка того аддон к которому относится зона. Для корректности работы при входе в игру откройте журнал рыбалки
- Окно показывающего "рыбу" в инвентаре и ее стоимость. Данные берутся из базы улова дополнения.
- Команды консоли `/fishstat`, `/fishstat reset`, `/fishstat minimap`

## Установка

1. Скопируйте папку `FishStat` в:
   `World of Warcraft\_retail_\Interface\AddOns\`
2. Активируйте **FishStat** в меню модификаций
3. `/reload`
